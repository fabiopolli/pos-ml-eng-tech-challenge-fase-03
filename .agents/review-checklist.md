# Checklist antes do pull request

- [ ] A branch segue `<tipo>/<integrante>/<descricao-curta>` e não é `main`.
- [ ] O diff contém apenas alterações da tarefa.
- [ ] Nenhum dado, segredo, modelo grande, cache ou ambiente foi incluído.
- [ ] Lint e testes relevantes passaram.
- [ ] Novos comportamentos têm testes proporcionais ao risco.
- [ ] Contratos afetados foram preservados ou a mudança foi aprovada e documentada.
- [ ] README e documentação descrevem o estado real.
- [ ] `docs/CHECKLIST.md` foi atualizado ou conferido sem necessidade de mudança.
- [ ] Evidências e comandos de validação estão no PR.
- [ ] Commits são pequenos, semânticos e compreensíveis.
- [ ] Há revisor diferente do autor.
- [ ] Mudanças de arquitetura possuem ADR quando necessário.
